Welcome to Ethiopia

This regional overlay displays the political boundaries and town data for the Ethiopian nation on EarthMC. Admins can unlock the console to manage regions, sync data, and perform topological operations.

Features visible to all: Interactive map with town markers, region boundaries, population stats. Click regions to inspect them. Export boundary data as GeoJSON.
